Control de variables de un invernadero

Desarrollo de una aplicación web para registrar condiciones del cultivo, interpretar los valores y generar un reporte escrito y hablado en español o inglés.

1. Introducción

En un invernadero, variables como la temperatura, la humedad y las condiciones del sustrato permiten conocer el ambiente en el que se desarrolla un cultivo. Para este trabajo se creó AgroControl, una página que recibe valores introducidos por el usuario, los compara con intervalos de referencia y redacta un informe del estado de cada variable.

La solución incorpora lectura en voz alta a través de la función de síntesis del navegador, con selección entre español e inglés. De esta manera, además de mostrar el resultado por escrito, permite escucharlo.

2. Objetivos

Objetivo general. Desarrollar una aplicación web que registre y analice variables de un invernadero y comunique los resultados por escrito y mediante voz en dos idiomas.

Objetivos específicos

  • Registrar los valores de temperatura, humedad ambiental, luminosidad y pH del sustrato.
  • Evaluar cada dato frente a los límites definidos en el proyecto.
  • Agregar el pH del sustrato como variable de seguimiento, según las instrucciones de la actividad.
  • Generar reportes en español e inglés y habilitar su reproducción por voz.
  • Publicar la aplicación e identificar sus alcances y posibilidades de mejora.

3. Descripción de la solución

La guía de orientación presenta un ejemplo inicial basado en temperatura y humedad. El trabajo final requiere incorporar la variable pH y otro idioma para comunicar el reporte. AgroControl mantiene esas funciones y añade luminosidad relativa para realizar una evaluación de cuatro condiciones.

La interfaz se elaboró con HTML, los estilos con CSS y la lógica con JavaScript. Los valores se ingresan manualmente o se cargan como ejemplo. Una vez introducidos, el usuario selecciona el idioma y pulsa Generar reporte. Si desea escuchar el diagnóstico, utiliza Escuchar reporte.

Para la lectura se usa la Web Speech API del navegador. No se ha acreditado en este informe una conexión activa con Azure ni la adquisición automática de datos desde sensores.

Los intervalos fueron elegidos para ejemplificar el funcionamiento del programa. No son recomendaciones agronómicas universales; para una aplicación real deberían establecerse de acuerdo con el cultivo, el equipo de medición y las condiciones de producción.

5. Desarrollo y funcionamiento

  1. El usuario introduce los cuatro valores o carga el conjunto de ejemplo.
  2. El programa revisa que los valores sean numéricos y estén dentro de los límites admitidos en los campos.
  3. Cada lectura se clasifica frente a su intervalo de referencia.
  4. Se crea un resumen en español o inglés según la selección del usuario.
  5. El navegador intenta reproducir el texto con su sistema de síntesis de voz.

8. Análisis y reflexión

El uso de reportes automáticos reduce el esfuerzo de interpretar varias lecturas de manera separada. La salida hablada también ofrece otra forma de consultar la información. Sin embargo, el resultado depende de que los datos se ingresen correctamente y de que los intervalos de referencia sean apropiados para el cultivo.

En una implementación empresarial se necesitarían sensores, una base de datos histórica, verificación de mediciones, alertas configurables y procedimientos para revisar las condiciones que se salgan de los límites. También sería necesario evaluar un servicio de voz en la nube si se exige específicamente una API cognitiva externa.

9. Conclusiones

AgroControl permite registrar y evaluar cuatro variables: temperatura, humedad ambiental, luminosidad relativa y pH del sustrato. La incorporación del pH amplió el caso inicial y el selector de idioma permitió obtener un reporte en inglés. La reproducción de voz se probó en el navegador, y la publicación con GitHub Pages permite que terceros accedan a la aplicación mediante una dirección web.

El proyecto demuestra el uso de tecnologías web para presentar información ambiental y producir informes comprensibles, al tiempo que identifica las mejoras necesarias para convertirlo en una herramienta de monitoreo con sensores reales.
